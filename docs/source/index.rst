Welcome to Pymatsci's documentation!
====================================

**Pymatsci**  (Python Materials Science) is a robust, open-source Python library for materials analysis. It is further packaged and developed on the basis of **Pymatgen**, a very powerful package of material analysis. Pymatsci is dedicated to quick and easy operations, so that people can get the results they want without taking too much time.

**DFT Agent** ships with pymatsci as the ``SurfAgent`` package: an LLM-driven assistant for surface calculations that takes a natural-language request, retrieves or cleaves the structure, prepares and submits the VASP job, and reports the result directly in the browser. See :doc:`the DFT Agent tutorial <./usage/tutorials/agent>` for its tutorial and the full list of supported operations.



Check out the :doc:`./usage/index` section for further information, including how to :doc:`\ ./usage/install` the project. Of course, you can also click `here`_ for a pdf instruction.

.. _here: https://pymatsci.readthedocs.io/_/downloads/en/latest/pdf/

   Although the current project is very crude, it is under active development.
